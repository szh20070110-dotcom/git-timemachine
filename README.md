# git-timemachine · 微信聊天动画

纯 HTML + CSS + 原生 JS 的微信聊天动画演示，零依赖、无构建步骤，双击 `index.html` 即可打开。

## 版本演进

| 版本 | 提交信息 | 内容 |
| --- | --- | --- |
| v1 | `v1 首版界面` | 顶部状态栏与导航栏、左右气泡、底部输入栏、5 条对话 |
| v2 | `v2 入场动画` | 消息逐条淡入上移、气泡缩放、对方正在输入、时间分隔线 |
| v3 | `v3 细节优化`（`v3-night` 分支） | 头像、气泡尾巴、图片消息、语音条、下拉刷新、夜间模式 |
| v4 | `v4 重做动画` | 回到干净的 v2 结构，改用 spring 缓动、消息间隔更长，不做夜间模式 |

## 为什么从 v3 回退

v3 把能想到的细节都堆了上去，但做完之后发现它偏离了这个项目的目标——展示「聊天动画」本身：

- **夜间模式抢走了主线**：深色气泡在同色系背景上对比偏弱，观感反而不如亮色干净；换肤也把注意力从消息节奏转移到了主题配色上。
- **交互过载稀释了节奏**：下拉刷新、语音条、图片消息都有各自的小动画，首屏承载了太多可玩元素，逐条消息的入场被淹没，观众不知道该看哪里。
- **结论**：回到 v2 的干净结构，把精力集中在入场动画本身——用 spring 缓动做出轻微回弹，把消息间隔拉长，让每条消息都有呼吸感。v3 的实验没有丢弃，完整保留在 `v3-night` 分支上，随时可以回看或摘取其中某一部分。

## 回退与恢复

```bash
# 回退演示：在 v3 上留一条退路，然后回到 v2
git branch v3-night
git reset --hard HEAD~1

# 需要时查看完整的 v3 细节实验
git checkout v3-night

# 看完回到主线（v4）
git checkout master
```

`git reset --hard` 会同时改写工作区，确认没有未提交的改动再执行。

## 动画实现要点（v4）

- 入场缓动 `cubic-bezier(0.34, 1.56, 0.64, 1)`：终点前轻微过冲，形成 spring 手感。
- 起始位移 `translateY(22px)` + `scale(0.86)`，透明度同步淡入。
- 消息间隔拉长到 1 秒以上，对方消息先显示「正在输入」三点，再整条弹出。
- 时间分隔线独立淡入，不参与气泡的缩放动画。
